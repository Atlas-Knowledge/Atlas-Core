# Versioning Policy

Atlas-Core follows Semantic Versioning.

## Major

Breaking architectural or governance changes.

Example:

```
1.0.0 → 2.0.0
```

---

## Minor

New capabilities.

Example:

```
1.0.0 → 1.1.0
```

---

## Patch

Documentation fixes.

Small improvements.

Bug fixes.

Example:

```
1.0.0 → 1.0.1
```

---

# Release Process

Every release follows:

```
Architecture Review

↓

Governance Review

↓

Documentation Review

↓

Repository Audit

↓

Release Candidate

↓

Stable Release
```
