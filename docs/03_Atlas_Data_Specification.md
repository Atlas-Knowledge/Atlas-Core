# Atlas Data Specification (ADS) v1.0

## Purpose

The Atlas Data Specification (ADS) defines the universal data standard used across the Atlas ecosystem.

Every object stored in Atlas must follow ADS.

---

# Core Objects

1. Entity

Represents anything that exists.

Examples:

- Human
- Planet
- Disease
- Material
- Organization

---

2. Question

Represents an unanswered or partially answered question.

---

3. Evidence

Represents supporting or contradicting evidence.

---

4. Relationship

Represents a connection between any two Atlas objects.

---

# Universal Rules

Every object MUST have:

- Unique ID
- Creation Date
- Last Updated Date
- Version
- Confidence Score
- Source References

---

# Philosophy

Knowledge is a living network.

Atlas does not store isolated documents.

Atlas stores connected knowledge.
