# Atlas Engine

## Vision

Atlas Engine is an open scientific knowledge engine designed to help humanity discover unanswered questions, connect knowledge across disciplines, and accelerate scientific discovery.

The project does not aim to replace scientists.
Its mission is to help scientists discover new connections, identify research gaps, organize evidence, and prioritize questions that can have the greatest positive impact on humanity.

## Core Mission

Help humanity discover what it does not yet know.

## Core Principles

- Evidence before conclusions.
- Every claim must have a source.
- Facts are separated from hypotheses.
- Unknown is not false.
- Scientific discovery is a continuous process.
- Transparency over certainty.

## Long-Term Goal

Build the world's largest knowledge graph focused on scientific discovery and unanswered questions.
