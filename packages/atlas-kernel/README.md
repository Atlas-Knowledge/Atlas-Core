# Atlas Kernel

## Overview

Atlas Kernel is the core foundation of the Atlas Engine.

It defines the universal language of knowledge.

Everything inside the Atlas ecosystem depends on the Kernel.

The Kernel does not contain:

- User Interface (UI)
- Database implementation
- AI models
- External services

The Kernel contains only the core concepts that describe knowledge.

---

## Core Objects

The Kernel defines four fundamental objects.

1. Entity

Anything that exists.

Examples:

- Human
- Planet
- Disease
- Material
- Organization

---

2. Question

Something humanity has not completely answered.

---

3. Evidence

Information that supports or challenges a claim.

---

4. Relationship

A connection between two Atlas objects.

---

## Design Rules

The Kernel must remain:

- Small
- Stable
- Independent
- Portable

No business logic.

No infrastructure.

No external dependencies.
