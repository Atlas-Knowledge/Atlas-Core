# RFC-0001

## Title

Atlas as a Knowledge Operating System

## Status

Accepted

## Motivation

Traditional knowledge systems focus on storing information.

Atlas focuses on discovering new knowledge.

Therefore Atlas must be designed as an operating system for knowledge rather than as a graph database.

## Decision

Atlas consists of:

- Kernel
- Knowledge Graph
- Truth Engine
- Reasoning Engine
- Discovery Engine
- AI Interface

The Knowledge Graph is a subsystem.

It is not the final product.

## Consequences

Future development must treat every new component as a module of the Knowledge Operating System.
