# How to Get Help

## General Questions

Use **GitHub Discussions** for:

- General questions
- Architecture discussions
- Usage guidance
- Design feedback
- Community conversations

---

## Bug Reports

Use **GitHub Issues** when you discover:

- Reproducible bugs
- Documentation errors
- Broken links
- Unexpected behavior

Please include:

- Environment
- Steps to reproduce
- Expected behavior
- Actual behavior
- Logs or screenshots (if applicable)

---

## Feature Requests

For new ideas or enhancements:

- Search existing Issues and Discussions first.
- If the proposal is significant, it may require an RFC before implementation.

---

## Security Issues

Please **do not** report security vulnerabilities publicly.

See:

```

```

for responsible disclosure instructions.

# Communication Principles

Atlas values:

- Respectful communication
- Evidence-based discussions
- Constructive feedback
- Long-term thinking
- Transparency

---

# Response Expectations

The Atlas maintainers aim to:

- Respond respectfully.
- Keep discussions constructive.
- Prioritize reproducible issues.
- Maintain transparency throughout the review process.

Response times may vary depending on contributor availability.
